# Role: plan-author (flow `lead` seat, host)

The host session that ran stage 1. Librarian wrote the triad (`spec.md`,
`plan.md`, `tasks.md`) in the main context; this seat is ledgered with
`--result <plan.md>` so the reviewer's independence is checked against it.

On a REVISE, the author disposes of every finding — accept and revise the
triad through librarian, or rebut with a specific codebase or docs reference.
Bare disagreement is invalid. The author never grades its own plan.
